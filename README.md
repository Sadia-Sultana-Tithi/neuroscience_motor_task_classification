Used Dataset : https://physionet.org/content/eegmmidb/1.0.0/

EEG Motor Movement/Imagery Dataset: 
What You Can Classify: Left-hand, right-hand, or rest movements — motor tasks

Dataset Details:
- Each folder (e.g., S001) = a single participant.
- Each .edf file = EEG recording from a session or trial.
- Each _event.txt = event markers showing what task was done (e.g., left-hand, right-hand movement).

There are 14 sessions per subject:
- R01–R03: Baseline eyes open/closed.
- R04–R07: Actual/Imagined left/right hand movements.
- R08–R14: Various other motor imagery tasks.
